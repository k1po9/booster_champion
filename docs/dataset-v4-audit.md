# dataset/v4 样例验收

## 结论

schema v4 的球事件标签、有限档位和ETA采集通过样例验收，可以进入多批采集。发现的唯一结构问题是比赛结束后Agent继续运行约9.5分钟并写入5654个 `FINISHED` 空帧；已修复为先收尾活动样本、写 `match_end`，随后停止该场采帧。同一Agent若重新进入新比赛，会生成新的 `match_id` 和 `match_start`。

## 修复后采集要求

1. 使用包含FINISHED停采修复的最新提交；
2. 每个文件应有 `match_end`；正常关闭Agent时还应有 `session_end`；
3. 若同一Agent进程运行多场，每场必须有独立 `match_id`；
4. 后续可开始批量采集，优先补足0.4和0.6 m/s的完整ETA到达，并继续保持五档踢球均衡。
