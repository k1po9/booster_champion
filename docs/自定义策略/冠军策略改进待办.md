# 冠军策略改进待办

> 状态：从 `dataset/v2/soccersim_1.jsonl` 与当前实现对照确认，暂不直接修改正式策略。先完成两项核心能力的接口、精度和回退设计，再进入策略接入。

## P0：核心能力

- [ ] 将自由滚动球预测从“短期 advisory”升级为可查询的时间路径：输出 `position_at(t)`、`velocity_at(t)`、停球点、停球时间、置信度、不确定度和失效原因。
- [ ] 建立机器人目标 ETA 能力：根据当前位姿、朝向、运动状态、目标点、路径长度和障碍修正，输出预计到达时间、不确定度与可达状态。
- [ ] 组合球时间路径与机器人 ETA，输出最早可达拦截点，不再以“追当前球位”或“盲目跑向最终停球点”作为唯一方案。
- [ ] 所有预测都必须有置信度门控、输出迟滞和当前球位回退；碰撞、再触球、边界反弹或断帧后立即失效。

## P1：已确认的策略缺口

- [ ] **追球闭环**：让预测拦截点真正进入 Chaser 移动目标；当前实现只用 0.25 s 领先点选 Handler，实际仍逐帧追当前球位。
- [ ] **定位球传接**：界外球和球门球必须选择可达队友/接球点，同时比较队友 ETA、对手 ETA 和传球线净空，禁止只使用固定几何点。
- [ ] **守门员定位**：区分居中、门线横移、拦截和出击；球远离威胁区时必须回到球门有效覆盖位，禁止在侧面持续原地踏步。
- [ ] **倒地恢复**：将倒地/非 walk 状态置于普通运动命令之上，减少无效模式切换和速度命令，并记录检测、起身请求、成功/失败和恢复耗时。
- [ ] **全队球权互斥**：同一时刻只允许一名 `BallOwner/Interceptor` 主动进入球周围；守门员出击时场上 Handler 必须让位或封锁二点。
- [ ] **动态踢球力度**：射门、解围和传球分类标定，根据目标距离与动作类型计算力度并限幅；不再全部回退到 1.5。

## P2：可观测性与验收

- [ ] JSONL 记录球预测输出、拦截点、目标 ETA、角色选择优势、原始/绕障目标、目标年龄和目标切换原因。
- [ ] 球能力验收：未来位置误差、停球点误差、停球时间误差、失效检测延迟。
- [ ] ETA 验收：从目标生效到到达的误差，分开统计静止启动、在途换目标、转向后直行、绕障和临近减速。
- [ ] 策略验收：首次触球时间、追球路径长度、目标切换数、双人同抢次数、传球成功率、守门员错误出击率、倒地恢复耗时和最终胜率。
- [ ] 保留默认策略 A/B 基线和独立能力开关；未达验收门槛不得再默认启用。

## 当前事实

- 自由滚动球模型已是 `src/tactics/ball_prediction.py` 中的正式纯 Python 能力，但停球点和时间路径尚未进入 Chaser 实际移动闭环。
- 机器人 ETA 只有实验校准结果：在途平移速度约 `0.716 m/s`，转向速度约 `0.879 rad/s`；静止启动、制动、换目标和绕障尚未形成正式 ETA 能力。
- 当前 Champion 的 Handler 成本仅为 `distance/0.716 + heading_error/0.879 + slot_bias`，它是排名启发式，不是真实到达时间。
