# 机器人到达时间 ETA 实验计划与结果

> 状态（2026-07-14）：保留为运动响应实验基线，不提升为正式 tactics 能力。最新策略路线不依赖完整机器人 ETA，而采用球轨迹预测、进攻动作看门狗和保守敌方压力时间。巡航/转向校准结果仍保留，便于以后需要时复用。

本实验为“预测球轨迹 + 机器人到达时间 = 最早相遇点”提供机器人运动侧模型。当前比赛日志记录机器人位姿和实际下发速度命令，但没有记录策略内部目标点、绕障后的临时目标和剩余路径长度，因此本轮只验证可识别的运动学组成，不把结果包装成完整的任意目标 ETA。

## 1. 实验范围

工具：`tools/cross_validate_robot_eta.py`。

```bash
python3 tools/cross_validate_robot_eta.py \
  --input dataset/v1 \
  --output analysis/v1
```

交叉验证仍以整场 JSONL 文件为单位，每次留出一场比赛。实验分为：

- 持续直行时，累计走过 0.25 / 0.50 / 1.00 m 的时间。
- 持续原地转向时，累计转过 0.25 / 0.50 / 1.00 rad 的时间。
- 从静止启动片段中估计反应延迟和加速度。

直行片段要求处于 PLAYING、线速度命令至少 0.25 m/s、转向命令不高于 0.25 rad/s、轨迹直线度至少 0.90。转向片段要求线速度命令不高于 0.08 m/s，转向命令至少 0.20 rad/s 且方向不反转。

## 2. 候选模型

直行巡航模型：

```text
v_ground = translation_gain * v_command
ETA_cruise = distance / v_ground
```

从静止启动的动力学先验：

```text
ETA_start = reaction_delay + accelerate_then_cruise(distance, acceleration, v_ground)
```

转向模型：

```text
yaw_ground = yaw_gain * yaw_command
ETA_turn = angle / yaw_ground
```

完整目标 ETA 将来需要组合：

```text
ETA_target = turn_cost + path_translation_cost + arrival_slowdown_cost
```

## 3. 数据量

- 可用持续直行片段：254。
- 被识别为从静止启动的直行片段：6。
- 可用原地转向片段：818。

因此巡航和转向结论的数据较充分，启动反应/加速度的数据不足。

## 4. 留出集结果

### 在途直行 ETA 绝对误差

| 距离 | 经验巡航模型 median / p75 / p90 | 样本数 |
| --- | --- | ---: |
| 0.25 m | 0.042 / 0.094 / 0.197 s | 254 |
| 0.50 m | 0.047 / 0.125 / 0.214 s | 182 |
| 1.00 m | 0.056 / 0.129 / 0.206 s | 97 |

### 转向 ETA 绝对误差

| 转角 | 经验转向模型 median / p75 / p90 | 样本数 |
| --- | --- | ---: |
| 0.25 rad | 0.199 / 0.281 / 0.415 s | 818 |
| 0.50 rad | 0.179 / 0.294 / 0.419 s | 715 |
| 1.00 rad | 0.178 / 0.292 / 0.410 s | 521 |

### 从静止启动动力学

| 距离 | dynamics median / p75 / p90 | 样本数 |

1米启动结果只有一个样本，不具有统计意义。

## 5. 全量校准参数

```text
translation_command_gain = 0.8945
reaction_delay_sec       = 0.3544   # 暂定，样本不足
acceleration_mps2        = 1.4294   # 暂定，样本不足
yaw_command_gain         = 0.8789
```

默认最大线速度命令为 0.8 m/s，因此经验巡航地面速度约为：

```text
0.8 * 0.8945 = 0.716 m/s
```

五折中的平移 gain 为 0.892～0.898，转向 gain 为 0.876～0.882，跨比赛非常稳定。反应时间为 0.203～0.500 s，漂移明显，原因是静止启动样本太少且当前日志无法区分“刚收到新目标”和“从转向阶段切换到直行”。

## 6. 当前结论

可以作为下一版 ETA 的可靠部分：

- 在途直行速度兑现率 `0.8945`。
- 转向速度兑现率 `0.8789`。
- 对持续直行的 0.25～1.00 m 行程时间预测。

暂时不能作为正式能力的部分：

- 从静止启动的反应时间和加速度。
- 任意目标点 ETA。
- 绕障、接近目标减速和频繁目标切换时的 ETA。

因此当前结果适合构建“粗 ETA 下界/先验”，尚不能直接决定硬性的球-机器人相遇点。

## 7. 下一轮需要记录的字段

为了验证真正的目标 ETA，应在每个控制 tick 增加：

```text
raw_target                 策略最初目标点
adjusted_target            绕障后实际跟踪目标/经由点
distance_to_target         当前到目标直线距离
planned_path_length        经由点后的预计路径长度
heading_error              当前朝向与目标方向夹角
motion_phase               turn / accelerate / cruise / brake / arrived
target_changed             本 tick 是否更换目标
target_age_sec             当前目标已经保持多久
observed_linear_speed      位姿窗口测得的地面速度
observed_yaw_rate          位姿窗口测得的地面角速度
arrived                    是否达到目标及实际到达时间
```

有这些字段后，下一版才能按目标事件构造训练样本：

```text
输入：距离、路径长度、角度、当前速度、障碍数量、是否刚换目标
输出：实际到达时间 / 是否在预测时间内可达
```

## 8. 后续实施门槛

将 ETA 沉淀到 `src/tactics/` 前至少要求：

- 每场比赛具有不少于 20 个明确的目标开始→到达事件。
- 至少覆盖静止启动、在途改目标、转向后直行、绕障和临近减速。
- 0.5～2.0 m 距离上的 ETA 中位误差不高于 0.20 s，p90 不高于 0.50 s。
- 各留出比赛中的主要参数稳定。
- ETA 输出带不确定度，最早相遇点必须有当前球位置回退。
