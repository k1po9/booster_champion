## 使用边界

- 参数可进入离线审查和 shadow 回放；本工具不修改策略，也不代表已经授权预测结果接管追球。
- 有效时域只覆盖训练过且事件前仍有效的未来时距；边界、门柱、二次触球等由上层场景判断截断。
- 正式封装继续遵守 `BallTrajectoryPrediction` 接口原则，并根据整场留出误差校准不确定度。
